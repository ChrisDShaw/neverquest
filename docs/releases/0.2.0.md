# Neverquest 0.2.0

3 November 2026 · source release · Git tag `v0.2.0`

## Changes

- Named runs are now **hunts**. Start a solo hunt or add group members, including people who loot nothing. Existing runs remain available as hunts.
- Hunt summaries show item values and suggest who pays whom to equalise the group's item loot. Coin is already shared evenly and is excluded from settlement. Confirm membership and review vendor estimates, agreed item values or explicit exclusions before settling.
- **Copy running summary** shares provisional values before a hunt ends. Unpriced items are flagged and payments are omitted until prices are complete. Finished hunts offer **Copy settlement**, or **Copy hunt summary** for solo play.
- Copied hunt messages use `p`, `g`, `s` and `c` and fit within 240 characters, with numbered messages for longer summaries.
- The **Hunt & group** overlay shows live member values and payments, supports adding/removing members, and opens the matching hunt details. Polling preserves a member name being typed.
- New overlays default to 100% background opacity. Existing saved opacity settings are preserved.
- Fixed a delayed dialog-close event that could prevent a reopened panel from updating.

## Requirements and upgrade

Windows source build; Node.js 22.12 or newer and npm are required. Follow the [setup instructions](../../README.md#get-started), including the separate Electron runtime installation. There is no installer.

Saved collection format remains version 1. Existing history, runs and overlay settings are preserved. Older runs default to solo hunts until their members are edited. Hunt members and agreed item values are saved locally.

## Verification and limitations

- All 87 automated tests passed, including six-player settlement, copper rounding, message splitting, saved hunt settings, running copies and overlay scope.
- JavaScript syntax checks and the public-file check passed.
- The isolated Electron smoke test passed for the feature changes, including overlay member editing, typing during polling and default opacity. Only version labels, the download user-agent and release documentation changed afterwards.
- `npm audit` reported 0 vulnerabilities in the pinned dependencies.
- Hosted Windows/Node.js CI results remain to be confirmed for the pushed commit. This checkout was not installed afresh for release verification.
- In-game paste length and overlay interaction with the game in windowed, borderless and full-screen modes still need manual verification. No game compatibility is claimed from the isolated smoke test.
- Group membership is entered manually and applies for the entire hunt. The ledger can miss group activity or include nearby players. Vendor estimates may change with recorded sales; agreed hunt-specific values remain saved.
