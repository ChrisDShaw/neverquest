# Neverquest 0.3.2

## Changes

- Fixed the loot-summary copy action disappearing when a hunt ended with unpriced items. **Copy loot summary** is now available in both hunt details and the hunt overlay for ended solo and group hunts.
- Unpriced summaries show known item values and unpriced counts, with the split pending prices. They include no payment instructions. Settlement copying becomes available once items are priced or explicitly excluded.
- Long summaries retain numbered messages of at most 240 characters. Character ownership and saved collection format are unchanged.
- The hunt overlay now chooses the most recently ended hunt by its end time. Ending a backdated hunt keeps it visible instead of jumping to a different hunt with a later start time.

## Verification

- All 100 automated tests passed, covering ended unpriced summaries, restart/copy validation, long group-message pagination and keeping a newly ended backdated hunt in the overlay.
- The source Electron smoke check passed, including copy controls in both the completed-hunt details and overlay, without touching the clipboard or real game data. The 0.3.2 installer built successfully and passed its packaged smoke check; syntax and public-file checks also passed.
- Releases include `SHA256SUMS.txt` for the installer, blockmap and update metadata; the release workflow adds the exact CI artifact hashes to GitHub release notes. Default installers remain unsigned.
