# Neverquest 0.3.1

## Changes

- The dashboard and overlays warn when a different character has newer ledger activity within the last 15 minutes, even with automatic switching off.
- Start hunt now checks recent character activity before showing the form. Switch to the more recently active character, or explicitly keep the selected character for a deliberate or backdated hunt.
- The form names the character and server whose ledger it will track. Hunt submission rechecks activity, catching a character change while the form is open.
- Switching characters keeps existing hunts with their original owner. No hunts or saved records are moved automatically.
- Character activity uses ledger file timestamps only. It does not inspect the running game and cannot prove who is logged in. Old, tied and implausibly future timestamps do not trigger a mismatch warning; failed discovery is stated in the form.
