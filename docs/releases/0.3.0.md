# Neverquest 0.3.0

3 November 2026 · Windows x64 installer and source release

## Changes

- Added a per-user Windows installer, app icon, desktop and Start-menu shortcuts, and uninstall support. Node.js is no longer required for installed builds.
- Installed builds check GitHub Releases in the background and download new stable versions. An **Update ready — Restart** button applies them when convenient; quitting also applies a ready update. Pending saves finish first.
- Added **Preferences → About & updates**, with version/signing status, a manual update check, release and support links, and a local diagnostic export containing only app and system information.
- Added Windows build automation. Ordinary builds produce test artifacts; matching stable version tags prepare draft releases with installer, update metadata, blockmap and SHA-256 checksums. Publication remains a separate step.
- Included runtime dependency notices in the installer and disabled dependency lifecycle scripts by default.

## Install and upgrade

Download `Neverquest-Setup-0.3.0.exe` and run it. The installer is **unsigned**: Windows may display an Unknown publisher or SmartScreen warning. Unsigned updates rely on GitHub HTTPS and release checksums and have no verified publisher signature.

The packaged target is Windows x64. The Electron runtime determines supported Windows versions; older Windows releases are not supported. This build has been checked on Windows build 26200. Other Windows versions still need installer verification.

Existing source-build history remains in `%APPDATA%\Neverquest`. Collection format stays at version 1; no data migration is required. Uninstall keeps saved records. Source builds can still be run with Node.js 22.12+ using the README instructions.

Automatic updating becomes useful once a newer packaged stable release is published. An absent public release reports an update error without blocking the app. Source and smoke-test builds never contact the update host.

## Verification and limitations

- All 93 automated tests passed, including update deduplication, failed-download retry, stable-only policy and save-before-install ordering.
- Source Electron workflow smoke check and packaged offline startup/IPC/update-screen smoke check passed.
- The unsigned installer and blockmap built successfully. Its archive was inspected for development/private files and required licence notices.
- Final syntax, public-file, release-version and whitespace checks passed. Release checksums were generated, and Authenticode inspection confirmed the installer is unsigned.
- Runtime dependency audit: no reported vulnerabilities. Full audit: 15 moderate findings propagated from minimatch in build tooling; no forced incompatible dependency changes were applied.
- Hosted CI, clean-account installation/uninstall, actual installed-version upgrades and game/overlay interaction require verification before claiming those paths as tested.
- No automatic data rollback is provided. Use a newer corrective release to recover from a bad application release; automatic downgrades are disabled.
